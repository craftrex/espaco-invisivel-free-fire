# Gerador de Espaço Invisível para Free Fire e WhatsApp (2026)

Este repositório contém documentação e referências para a utilização de caracteres invisíveis e códigos transparentes em jogos mobile e redes sociais.

## O que é o Espaço Invisível?

O espaço invisível utiliza códigos Unicode especiais, como o **U+3164 (Hangul Filler)** e **U+2800 (Braille Pattern Blank)**, que permitem criar espaços e caracteres transparentes em campos de texto que normalmente bloqueiam a barra de espaço comum.

### Principais Usos:
- **Free Fire:** Deixar espaço no meio do nick ou usar nome 100% invisível.
- **WhatsApp:** Enviar mensagens em branco e criar quebras de linha limpas.
- **Instagram & TikTok:** Personalizar a biografia com espaçamentos perfeitos.
